# ローカル専用動作の要件ドキュメント

## 作成日
2026-02-16

## 目的
AWS系のリソースを使わずに、完全にローカル環境のみでゲームを動作させる方法を明確化する。

## 現状分析

### 現在の実装状況
このゲームは既に**ローカル専用動作が可能**な設計になっています。

#### AWS関連の設定（すべてオプション）
- `API_BASE`: 空文字列の場合、ローカルストレージにフォールバック
- `IMG_BASE`: 空文字列の場合、ローカルの`images/`フォルダを使用
- Amplifyフォルダ: バックエンド設定用（使用しない場合は無視される）

#### 自動フォールバック機能
```javascript
// game.js より
const API_BASE = ''; // 空のままだとローカル保存にフォールバックします
const IMG_BASE = ''; // 空の場合はローカル画像を使用
```

## ローカル専用動作の確認方法

### 1. 現在の設定確認
`game.js`の冒頭部分を確認：
```javascript
const API_BASE = '';  // ← 空文字列であることを確認
const IMG_BASE = '';  // ← 空文字列であることを確認
```

### 2. 必要なファイル構成
```
プロジェクトルート/
├── index.html
├── styles.css
├── game.js
└── images/
    ├── front-face.v1.png      # カード表面
    ├── background-image.v1.png # 背景画像
    ├── 01.v1.png              # カード裏面（1番）
    ├── 02.v1.png              # カード裏面（2番）
    ├── ...
    └── 59.v1.png              # カード裏面（59番）
```

### 3. 動作確認手順

#### 方法1: ブラウザで直接開く
1. `index.html`をダブルクリック
2. ブラウザで開く
3. ゲームが動作することを確認

**注意**: 一部のブラウザでは`file://`プロトコルでCORSエラーが出る可能性があります。

#### 方法2: ローカルサーバーを起動（推奨）
```bash
# Python 3の場合
python3 -m http.server 8000

# または Python 2の場合
python -m SimpleHTTPServer 8000

# またはNode.jsのhttp-serverを使用
npx http-server -p 8000
```

その後、ブラウザで`http://localhost:8000`にアクセス。

## データ保存の仕組み

### ローカルストレージ使用
- **保存先**: ブラウザのlocalStorage
- **保存キー**: `memoryGameRanking`
- **保存内容**: 
  - プレイヤー名
  - 揃えたペア数
  - 経過時間
  - プレイ日時

### データの永続性
- ブラウザのキャッシュをクリアすると削除される
- 同じブラウザ・同じドメインでのみ共有される
- プライベートブラウジングモードでは保存されない

## AWS関連ファイルの扱い

### 削除可能なファイル/フォルダ
以下はローカル専用動作には不要です：

```
amplify/              # 完全に削除可能
amplify.yml           # 完全に削除可能
package.json          # AWS SDKの依存関係が含まれるが、ゲーム動作には不要
package-lock.json     # 同上
```

### 削除する場合の注意
- `amplify/`フォルダを削除してもゲームは動作します
- ただし、将来的にAWSを使いたい場合は残しておくことを推奨

## トラブルシューティング

### 画像が表示されない
**原因**: 画像ファイルのパスが正しくない

**解決方法**:
1. `images/`フォルダが存在することを確認
2. 画像ファイル名が正しいことを確認（例: `01.v1.png`）
3. `game.js`の設定を確認：
   ```javascript
   const IMG_PREFIX  = '';      // 'images/'にしない
   const IMG_VERSION = 'v1';    // バージョン名
   const USE_PADDED  = true;    // 01.png形式の場合true
   ```

### ランキングが保存されない
**原因**: localStorageが無効化されている

**解決方法**:
1. ブラウザの設定でCookieとサイトデータを有効化
2. プライベートブラウジングモードを使用していないか確認
3. ブラウザのコンソールでエラーを確認

### CORSエラーが出る
**原因**: `file://`プロトコルでの制限

**解決方法**:
ローカルサーバーを起動して`http://localhost`経由でアクセス

## まとめ

### 現在の状態
✅ **既にローカル専用動作が可能**
- `API_BASE`と`IMG_BASE`が空文字列
- 自動的にローカルストレージとローカル画像を使用

### 必要な作業
❌ **特になし**
- 現在の設定のままで完全にローカル動作します
- AWS関連のファイルは無視されます

### オプション作業
- Amplifyフォルダの削除（将来使わない場合）
- package.jsonの整理（AWS依存関係の削除）

---

**結論**: このゲームは既にローカル専用で動作可能です。`index.html`をブラウザで開くか、ローカルサーバーを起動するだけで使用できます。
